# Project Overview

Secret Faede is a private Garden OS for one real home food garden. The app keeps Firebase email/password auth for exactly two provisioned accounts and routes authenticated users into Plan, Today, Feed, and Settings around one shared published garden with private drafts.

The product center is the real plot editor and practical garden operations. Active scope includes sign-in, auth routing, access-denied handling, the authenticated app shell, a saved garden editor, generated task timelines, succession suggestions, notification preferences, in-app/web/native alerts, journal notes, issue tracking, photo attachments, harvest logs, summaries, Firebase deployment scaffolding, tests, CI, and docs.

Guardrails: do not add dashboards, charts, maps, collaboration, lore, AI, carrier messaging, public onboarding, or product scope beyond the plot editor and directly supporting operations.
